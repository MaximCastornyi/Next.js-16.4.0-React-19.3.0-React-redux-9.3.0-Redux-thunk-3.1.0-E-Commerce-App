# Next.js-16.4.0-React-19.3.0-React-redux-9.3.0-Redux-thunk-3.1.0-E-Commerce-App
This is an application for selling products online, featuring an authorization and authentication system powered by NextAuth.js. It utilizes MongoDB Cloud, React Redux, and PayPal integration; it also employs a Google application to send email confirmations and incorporates Mailchimp.

Before using the code, don't forget to create a database dump and upload it to MongoDB Cloud.
